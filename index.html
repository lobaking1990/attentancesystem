☁️ Google Cloud Sync

Laman ini berjalan melalui GitHub Pages HTTPS supaya kamera QR boleh digunakan. Data cloud kekal disimpan dalam Google Sheets melalui Google Apps Script.

Belum disambungkan.
Setup sekali pada setiap device: masukkan URL /exec dan Sync Key, kemudian tekan Simpan Sambungan dan Uji Cloud.

Sync Key tidak disimpan dalam GitHub. Ia hanya disimpan dalam browser device ini. Data local storage kekal sebagai salinan kecemasan jika internet terputus.
Google Apps Script perlu dideploy sebagai Web app, Execute as: Me, dan akses Anyone. Sync Key melindungi data cloud walaupun laman GitHub adalah public.
